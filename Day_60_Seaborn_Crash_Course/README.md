# Day 60: Seaborn Statistical Data Visualization

## Project Overview

Continuing the Data Science and Machine Learning track, this module focuses on statistical data visualization using the `seaborn` library. The exercises cover analyzing built-in datasets (`tips`, `flights`, `iris`) to uncover patterns, distributions, and correlations through advanced matrix and categorical plotting.

## Skills Demonstrated

* **Distribution Plots:** Visualizing univariate and bivariate distributions using histograms, kernel density estimations (KDE), and `jointplot` with regression lines.
* **Categorical Data Plotting:** Comparing metrics across different categories using `barplot` (with standard deviation estimators), `countplot`, `violinplot`, and `swarmplot`.
* **Matrix Plots:** Reshaping data with Pandas `pivot_table` to create multi-variable visualizations like `heatmap` and hierarchically-clustered `clustermap` arrays.
* **Grid Graphics:** Generating comprehensive `pairplot` matrices to instantly visualize pairwise relationships across entire dataframes grouped by specific categories (hues).
