# Day 44: Motivational Meme Project

## Project Overview

A practical exercise in CSS positioning and typography. This project builds a classic "Motivational Poster" layout, emphasizing document flow, element centering via margins, and the integration of external web typography (Google Fonts).

## Skills Demonstrated

* **Web Typography:** Importing external font families (`Libre Baskerville`) from Google Fonts and applying them to specific HTML elements.
* **CSS Layout & Centering:** Horizontally centering block-level elements (`<div>`) by calculating width percentages (`width: 50%`) and applying complementary auto/percentage margins (`margin-left: 25%`).
* **Text Transformation:** Utilizing the `text-transform: uppercase;` property in CSS to visually alter text rendering without modifying the underlying HTML structure.
* **Box Model Styling:** Applying borders and background colors to create high-contrast, visually distinct layout segments.

## How to Run

No backend server is required. Ensure `index.html`, `style.css`, and the `/assets/images/` directory (containing your image) are in the same folder structure. Open `index.html` in any modern web browser.
