# Day 43: HTML Birthday Invite Project

## Project Overview

A foundational Web Development exercise focusing on building a static HTML event invitation. This project introduces embedding external media, structuring unordered lists, and implementing hyperlinks to external web services like Google Maps.

## Skills Demonstrated

* **Media Embedding:** Using the `<img>` tag with `src` and `alt` attributes to display external images and ensure accessibility.
* **Unordered Lists:** Structuring itemized data (party requirements) using `<ul>` and `<li>` tags.
* **Hyperlinks:** Utilizing the anchor `<a>` tag with the `href` attribute to route users to external locations (Google Maps).

## How to Run

No backend server is required. Open `index.html` in any modern web browser to view the invitation.
