# Day 41: HTML Movie Ranking Project

## Project Overview

This project marks the transition into Web Development. It is a foundational HTML5 exercise focused on semantic document structuring. The page renders a simple, hierarchical list of top movies, demonstrating a clear understanding of text formatting and structural tags.

## Skills Demonstrated

* **Semantic HTML Structuring:** Utilizing hierarchical heading tags (`<h1>`, `<h2>`, `<h3>`) to establish a clear document outline and importance logic.
* **Content Formatting:** Applying paragraph tags (`<p>`) for standard text and horizontal rules (`<hr />`) for thematic breaks and visual separation.
* **Web Foundation:** Establishing the core markup layer that will later be styled with CSS and manipulated via DOM scripting.
