# Day 27: Mile to Kilometers Converter

##  Objective
Introduction to Graphical User Interfaces (GUI) in Python using the `tkinter` module. The goal of this project is to build a functional desktop application that converts distances from miles to kilometers based on user input.

##  Concepts Applied
* **Tkinter Basics:** Creating windows, configuring dimensions, and setting up the main event loop (`mainloop`).
* **Widget Placement:** Using the `grid()` geometry manager to align labels, entry boxes, and buttons in a structured layout.
* **Event Driven Programming:** Binding a button click to a custom Python function (`command=button_clicked`) to execute the mathematical conversion dynamically.
